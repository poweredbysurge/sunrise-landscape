# Location Page Differentiation Matrix
Every location page pulls its unique ingredients from THIS table. Ingredients are never shared between pages. If a cell is used on one page, it is off-limits everywhere else.

## Openers (rotate, max 5 pages per opener style)
- **A. Problem-first:** open on the lawn/yard problem this city's homeowners actually have.
- **B. Place-first:** open on a concrete geographic fact (lot sizes, tree cover, soil, slope).
- **C. Proof-first:** open on a real Sunrise project or client result in that city.
- **D. Season-first:** open on what the yard needs right now in NoVA's calendar.

## Hard rules
1. A neighborhood appears on exactly ONE page, ever.
2. A testimonial or featured project appears on exactly ONE page.
3. No two same-type pages adjacent in the table use the same opener.
4. Each "local knowledge angle" is a real, checkable statement about that place. If we cannot verify a local claim, we write about the service specifics instead. Never invent city facts.
5. The swap test from PAGE-STANDARDS.md is run on every pair of same-type pages before merge.
